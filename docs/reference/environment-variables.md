# Environment variables (frontend)

All configuration lives at the **repository root**. There are no `apps/*/.env` files.

## Files

| File                       | When                                                     |
| :------------------------- | :------------------------------------------------------- |
| `.env.development`         | Local `pnpm dev`, fallback when Infisical is unavailable |
| `.env.production`          | Production builds, K8s secrets                           |
| `.env.infisical`           | Generated by Infisical export (Docker dev/prod compose)  |
| `.env.development.example` | Template / Infisical import reference                    |
| `.env.production.example`  | Template / Infisical import reference                    |

## Loading

- **Next.js** (`pnpm dev` / `build`): `import '@nestlancer/config/load-root-env.mjs'` in each `next.config.mjs` loads `.env.development` or `.env.production`, then overlays `.env.infisical` if present.
- **Docker**: `env_file: .env.infisical` in compose files; create with `scripts/docker/compose-dev.sh` or `compose-prod.sh`.

## Required variables

| Variable                       | Description                                                            |
| :----------------------------- | :--------------------------------------------------------------------- |
| `NEXT_PUBLIC_API_URL`          | Browser REST base (often same-origin with proxy in Docker/prod)        |
| `NEXT_PUBLIC_WS_URL`           | Socket.IO origin (defaults to API URL in components if unset)          |
| `NEXT_PUBLIC_SOCKET_IO_PATH`   | Engine path (default `/ws/socket.io`)                                  |
| `API_UPSTREAM`                 | Server-side gateway for Next rewrites and auth BFF                     |
| `NEXT_PUBLIC_APP_URL`          | Web app public URL (client portal, landing links)                      |
| `NEXT_PUBLIC_ADMIN_APP_URL`    | Admin app public URL (cross-portal auth links)                         |
| `NEXT_PUBLIC_RAZORPAY_KEY_ID`  | Razorpay checkout — **must match** backend `RAZORPAY_KEY_ID`           |
| `NEXT_PUBLIC_AUTH_REFRESH_BFF` | Passed into Docker build (`true` = HttpOnly refresh via `/api/auth/*`) |

## Production / Docker proxy

| Variable                | Description                                         |
| :---------------------- | :-------------------------------------------------- |
| `NEXT_PUBLIC_API_PROXY` | `true` to call same-origin `/api/v1` (Next rewrite) |

Compose sets `NEXT_PUBLIC_API_URL` per app (`dev-web`, `dev-admin`, etc.) with `NEXT_PUBLIC_API_PROXY=true` and `API_UPSTREAM` pointing at the gateway.

## Logging (server → container stdout)

| Variable             | Description                                                                                     |
| :------------------- | :---------------------------------------------------------------------------------------------- |
| `LOG_LEVEL`          | `debug` \| `info` \| `warn` \| `error`. Dev Infisical: `debug`; prod: `info`                    |
| `NESTLANCER_SERVICE` | Optional override for log `service` field (Compose sets `nl-prod-frontend-{web,admin,landing}`) |

Structured JSON logging: [`docs/operations/logging.md`](../operations/logging.md). View with `pnpm docker:prod:logs` / `pnpm docker:logs:web`.

## Turnstile (Cloudflare)

| Variable                             | Description                                                              |
| :----------------------------------- | :----------------------------------------------------------------------- |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY`     | Public site key (Infisical `dev` + `prod`). Enables widget when set      |
| `NEXT_PUBLIC_TURNSTILE_BYPASS_TOKEN` | Dev only — must match backend `TURNSTILE_BYPASS_TOKEN`; **omit in prod** |

Backend holds `TURNSTILE_SECRET_KEY` (never store the secret in the frontend Infisical project).

## Development-only

| Variable                | Description                    |
| :---------------------- | :----------------------------- |
| `NEXT_PUBLIC_DEBUG_API` | Admin API debug panel (`true`) |

## Optional

| Variable                                             | Description                                                                  |
| :--------------------------------------------------- | :--------------------------------------------------------------------------- |
| `OPENAPI_GATEWAY_URL`                                | OpenAPI pull scripts (`scripts/openapi/`)                                    |
| `NEXT_PUBLIC_WEB_URL`                                | Admin blog/portfolio preview base (defaults to `NEXT_PUBLIC_APP_URL`)        |
| `NEXT_PUBLIC_LANDING_URL`                            | Marketing origin (landing redirects / links)                                 |
| `NEXT_PUBLIC_WEB_PUSH_PUBLIC_KEY`                    | VAPID public key — **must match** backend `VAPID_PUBLIC_KEY`                 |
| `NEXT_PUBLIC_RAZORPAY_CHECKOUT_CONFIG_ID`            | Razorpay Payment Configuration — match backend `RAZORPAY_CHECKOUT_CONFIG_ID` |
| `NEXT_PUBLIC_FEATURE_COMMAND_PALETTE_WEB`            | `true`/`false` — web command palette (default on)                            |
| `NEXT_PUBLIC_FEATURE_COMMAND_PALETTE_ADMIN`          | Admin command palette (default on)                                           |
| `NEXT_PUBLIC_FEATURE_PROJECT_HUB_CONTRACT_STRIP`     | Project hub contract strip (default on)                                      |
| `NEXT_PUBLIC_FEATURE_LANDING_HERO_REVAMP`            | Landing hero variant (default on)                                            |
| `NESTLANCER_IMAGE_REGISTRY` / `NESTLANCER_IMAGE_TAG` | Docker image tags for `docker-compose.prod.yml`                              |

## Backend alignment

| Frontend                                  | Backend                                                     |
| :---------------------------------------- | :---------------------------------------------------------- |
| `NEXT_PUBLIC_RAZORPAY_KEY_ID`             | `RAZORPAY_KEY_ID`                                           |
| `NEXT_PUBLIC_RAZORPAY_CHECKOUT_CONFIG_ID` | `RAZORPAY_CHECKOUT_CONFIG_ID`                               |
| `NEXT_PUBLIC_WEB_PUSH_PUBLIC_KEY`         | `VAPID_PUBLIC_KEY` / `NOTIFICATION_WORKER_VAPID_PUBLIC_KEY` |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY`          | pairs with backend `TURNSTILE_SECRET_KEY`                   |
| `NEXT_PUBLIC_TURNSTILE_BYPASS_TOKEN`      | `TURNSTILE_BYPASS_TOKEN` (dev only)                         |
| `API_UPSTREAM` / `NEXT_PUBLIC_WS_URL`     | Gateway + `ws-gateway` deployment                           |
| `NEXT_PUBLIC_APP_URL`                     | `FRONTEND_URL` (email links)                                |

See [infisical.md](./infisical.md) for secrets manager setup and [logging.md](../operations/logging.md) for container logs.
